# note有料記事リサーチ

noteの検索APIから有料記事だけを集め、スキ数の多い順にCSVへ出力する。

## 実行

```bash
python3 .claude/skills/note-research/note_research.py --min-likes 100 --out note_paid.csv
```

- `--genre ジャンル=語1,語2` を繰り返して対象を指定する。省略時は 育児(育児,子育て)/勉強(勉強,勉強法,資格)/旅行(旅行,旅)
- `--min-likes` スキ数の下限(既定0)
- `--pages` 1語あたりのページ数。1ページ20件(既定10)

ユーザーがジャンルや下限を指定したらそれを引数に渡す。

## 結果のまとめ方

CSVを読み、ジャンルごとに上位10件を表で示す(タイトル・価格・スキ数・コメント数・著者・URL)。続けて、ジャンルごとに価格帯、売れ筋タイトルの共通点(数字・対象読者・悩み)を短く添える。

## 注意

- noteは購入数を公開していない。「売れている」はスキ数・価格・フォロワー数から推定するしかなく、`推定売上指標`(スキ数×価格)は比較用の目安で実売上ではない。結果を伝える時もそう明記する
- noteの評価はスキだけで、高評価と低評価の区別はない
- API呼び出しの間に1秒待つ。ページ数を大きくしすぎない
